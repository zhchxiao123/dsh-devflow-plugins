# 自动化侧栏

[English](README.md) | 中文

通过 DeepSeek Harness 原生页面注册表和 keyed body slot，在右侧栏加入**自动化**入口。页面展示当前主机的全部订阅和计划，与当前聊天工作区无关。Devflow 原有看板保持独立。

与 `dsh-automation-web`、`dsh-scheduler-local` 和 `dsh-github-sync-local` 组合使用。浏览器产物要求 Harness `0.1.5-rc.2`；打包前在仓库根目录构建。缺失服务会明确显示。

GitHub 页支持新建订阅、修改同步范围和凭证引用、暂停与恢复、立即同步，以及通过纯文本和安全来源链接查看内容。凭证填写 `env:GITHUB_TOKEN` 这样的引用，密钥值不会进入面板。

定时计划支持固定间隔、带明确时区的 Cron、立即执行、暂停与恢复，以及保留历史的计划删除。新建计划选择 GitHub 订阅；编辑其他处理器的现有计划时保留其参数。

运行记录展示状态、时间、页数、内容数、重试次数、等待、错误、回执、取消，以及失败或部分完成的 GitHub 运行恢复。GitHub 页支持调整容量。面板与 agent 工具调用相同公共服务，修改后重新读取已提交状态。

概览与内容各自仅允许一个请求进行，慢响应不会被后续轮询中断。写入错误保留至主动关闭或再次操作；概览读取成功不会清除内容或写入错误。仅可见面板轮询；浏览器隐藏时跳过刷新，面板隐藏时中止读取，卸载时清理定时器和监听。刷新失败保留旧数据并明确提示。浏览器插件 `refreshMs` 默认 5000，接受 100 至 2147483647 的整数毫秒。
