# 项目自动化与 GitHub 侧栏页面

[English](README.md) | 中文

在 DeepSeek Harness 原生右侧栏加入两个独立页面：**自动化**（`automation`）管理定时计划和投递记录，**GitHub 订阅**（`github-subscriptions`）管理订阅、同步内容和同步运行。Devflow 保持独立页面。

每个请求携带侧栏实际会话 ID，由主机解析已注册的工作区，并在控件上方展示项目名称。同一项目的会话共享记录，不同项目彼此隔离。缺少上下文时提示先打开项目会话，不会退回主机全局列表。页面关闭后，后台任务仍由主机管理执行。

与 `dsh-automation-web`、`dsh-scheduler-local`、`dsh-github-sync-local` 组合使用。浏览器产物要求已发布的 Harness `0.1.5-rc.2`；打包前在仓库根目录构建。缺失服务会明确显示。

GitHub 订阅支持编辑同步范围和凭证引用、暂停与恢复、立即同步，以及纯文本内容和安全来源链接。凭证填写 `env:GITHUB_TOKEN` 这样的引用，密钥值不会进入面板。**设置定时同步**打开原生自动化 Tab，并预选该订阅。订阅关联计划、投递关联运行通过会话绑定的原生导航操作在两个 Tab 之间跳转。

定时计划支持固定间隔、带明确时区的 Cron、立即执行、暂停与恢复，以及保留历史的删除。新建计划选择当前项目订阅；修改现有处理器计划的时间规则时保留其参数。同步运行展示状态、时间、页数、内容数、重试次数、等待、错误、取消，以及失败或部分完成后的恢复。投递记录与同步完成状态分别展示。

旧数据仅在主动读取**未归属项目的旧数据**后显示。每条记录均需显式认领，才能将记录及历史绑定到当前项目；计划关联的订阅需先认领。GitHub 存储限制跨项目共享，因此明确标注为**主机共享存储容量**。

概览与内容各自仅允许一个读取请求。隐藏面板中止读取，卸载清理定时器与监听。切换会话或导航时重建组件生命周期；项目绑定变化时清除旧表单与内容，忽略过时写入结果。刷新失败保留旧数据并标注过时，但缺少项目上下文时移除旧视图。独立的概览刷新成功不会清除写入或内容错误。浏览器插件 `refreshMs` 默认 5000，接受 100 至 2147483647 的整数毫秒。
