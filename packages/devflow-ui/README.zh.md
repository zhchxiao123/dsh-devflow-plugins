# @zhchxiao123/dsh-devflow-ui

[English](README.md) | 中文

Devflow 看板插件（浏览器半边）。看板有**两套面，且任一时刻只出现一套**：组合了 [`dsh-better-sidebar`](https://github.com/omdsh-dev/DSH-better-sidebar) 底座的部署里，它注册一个侧边栏页面（`dsh-devflow:board`，单实例，排在底座自带页面之后），头部控件根本不注册；其余部署里就是下面描述的悬浮控件。插件里由**同一处**根据底座是否在场做出选择，并在底座出现或离开时换掉已挂载的那一套——因此两者不可能同时出现。底座既不被 import 也不被声明为依赖：只在本地重述本插件调用的那一小片服务，一切经服务名交互，既满足 client bundle 纯度门，也让没有底座的部署行为逐字节不变。底座拒绝该页面（id 冲突）只告警，插件其余部分照常运行。

侧栏页面是一整列高度：头部承载标题（打开详情时是返回控件），其下是本工作区的卡片总数与分布（进行中 / 受阻 / 已完成，三个桶恰好划分总数）与一排阶段筛选片——把列表收窄到某一个位置时，自身阶段未命中的需求会作为命中子卡的上下文保留，它的 `k/n` 仍然按整个拆分计数。再往下，层级卡片列表填满剩余高度并滚动。打开一张卡后，列表让位给它的详情表单，四段——需求书、拆分关系、阶段产物、流转时间线——都是默认展开、可各自折叠的分段，时间线终于有了地方。底座能够持久化并重新发布页面设置时，该页面的设置卡上会出现"并列"开关：打开后列表在详情旁常驻，而不是被它取代。

侧栏页面呈现的是**它自己 scope 的**工作区，而不是应用当前摆在前面的那个会话：绑定按会话分桶，每个页面各取各的。它在成为展开面板里的可见 tab 时拉取；变更帧重取的是"可见页面正在关注的 scope"加上被选中会话——也就是 tab 角标与 `+` 菜单报告的那个——因此属于其他会话的后台 tab 不产生任何开销，而用户眼前的角标保持实时。被选中会话的看板另外在变更流每次建立时以及每次真实的选择变化时刷新。tab 角标报告上一次拉取得到的进行中卡片数（自身绝不发起请求），计数口径与页面统计头完全一致，且只在底座宣告 `badge` 能力时才提供。已知没有卡片的工作区把页面呈现为不可用而非隐藏；尚未拉取过的工作区保持可打开，因为打开正是拉取的触发点。

悬浮面是经 body portal 锚定在对话区右上角的控件（注册在会话头部工具 slot 上只为生命周期，渲染在其外，头部的层叠上下文因此困不住它）。收起态是一颗显示进行中数量的胶囊（全部 `done` 时显示空闲文案）；展开态加上只读面板——带收起按钮的标题栏、每卡一行（状态点、id、标题、本地化阶段含受阻来源、按状态着色的七段阶段进度条、revision），以及汇总 footer。列表只有一层:拆分需求领头,它的子卡缩进排在其下,它自己那行还带 `k/n` 拆分进度与子卡受阻标记。每行的折叠控件可把子卡收起再展开;父卡不在本次列表里的子卡(先一步被归档)平铺为顶层行,因此没有卡片会消失。点击一行,列表切换为该卡的只读详情:标题与身份、标注全部阶段名的放大流水线、需求正文 Markdown(经共享的 `MarkdownText` 渲染件,验收清单不可交互)、拆分关系(子卡的父卡反链、父卡的子卡清单,均可钻取到该卡详情)、已登记产物——每条登记一行,呈现 kind(早于 kind 的登记以中性占位)、登记阶段与 revision,被取代的旧版本仍然列出,同一 kind 重复登记的最新一份带"最新"标记——卡片文件路径,以及流转时间线——每条 journal 记录从新到旧呈现执行者、打回原因、审批签名、已记录的闸门放行(每条 check 一行,呈现执行者与 summary,缓存裁决的 `[cached]` 前缀原样保留)与接管记录,头部是带心跳新鲜度的当前租约持有者与客户端派生汇总(卡龄、打回次数;手写时间戳不可解析时时长静默省略)。时间线上客户端会话列表认识的 agent 渲染为可点击反链、切到那次会话;已消失的会话保持纯文本。详情在每次打开时经聚合的 `detail` 读取拉取(卡 + 条目 + 持有者一次往返),随每一帧变更与看板一同刷新,切换会话(卡片属于旧工作区)或拉取失败即关闭,返回控件回到列表且不收起面板。看板数据经本插件自持的读取面路由到达——由 [`dsh-devflow-web`](../../devflow/devflow-web/README.zh.md) 在与应用同源的位置提供——并以当前选中会话为作用域：每次拉取只 POST 该会话的 id（绝不发路径），host 把它的工作区解析成 devflow 根，切换会话即切换看板。知道通路的只有绑定层这一个模块；视图、页面与两面选择器拿到的都是值。实时性同样自持：一条通往 host `/devflow/ws` 端点的下行 socket，每次建卡或阶段移动送来一帧，帧里只说明有东西动了。断开的 socket 以从两秒起翻倍、上限三十秒的延时重连，并在下一次打开时复位，因此一次抖动只花下限，而一直不起来的 host 也不会被反复砸。看板在激活时取一次，在这条 socket 每次打开时取一次（第一次与每次重连都算，因为断过的看板无从知道自己错过了什么），每次真实的选择变化取一次，每来一帧再取一次，聊天建的卡因此无需刷新即出现——落入插件持有的可观察快照并经 hooks 隔间绑定，因此胶囊与打开的面板永远显示同一次拉取的卡片。没有 devflow 的工作区（或拉取失败）完全不渲染控件。

本插件不发出任何变更：卡片移动属于模型侧 devflow 工具与干预命令面，人工审批走现有的审批 composer——gates 插件把它们路由到 `ctx.approval`。

## Model Experience

None, as this package renders fetched board state for a human and touches no prompt, message, schema, stream, or tool result. The model's own view of the same cards stays with [`dsh-tool-devflow`](../../devflow/tool-devflow/README.zh.md).

#### KV Cache effect

None; the package never assembles or sends provider requests.

## Known Limitations and Deferred Work

- **行按设计只读** — PRD 的三操作面把语义移动留在聊天面、干预留在 `/devflow`；面板未来唯一的可操作元素是应答待审批项，如今经审批 composer 呈现。
- **每帧变更全量重拉** — 每一帧都完整重拉看板；增量帧等看板大到需要时再来。
- **拆分标记只看得见 `blocked` 子卡** — 列表携带的是当前阶段而非历史，因此被打回到 `developing` 的子卡与正常走到那里的子卡无法区分；要在父行呈现打回，需要每张子卡的 journal。
- **折叠状态随挂载存在** — 折起一个需求是打开中面板的视图偏好而非存储项，面板重新挂载即复位。
- **非选中会话的页面持有过期角标** — 变更帧刷新的是被选中会话与可见页面关注的 scope；固定在另一个会话、既不可见也未被选中的页面会一直报告上一次的计数，直到它再次显示。
- **侧栏面靠桩服务验证** — 底座是工作区之外的生态插件，无法在测试通道里启动，因此注册、互斥与拉取门由桩服务加 jsdom 里的页面渲染证明；真实侧栏靠手测。
