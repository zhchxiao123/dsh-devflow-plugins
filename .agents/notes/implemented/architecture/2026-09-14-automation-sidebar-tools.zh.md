# Agent Note: 原生自动化侧栏与工具消费者

Status: implemented

[English](2026-09-14-automation-sidebar-tools.md) | 中文

## Problem

斜杠命令提供了调度和 GitHub 同步能力，但用户需要记忆语法并阅读原始记录。用户需要自然语言控制和持续查看运行的入口，同时区分已接收与同步完成。

## Decision

新增独立的调度与 GitHub 工具消费者、宿主级 HTTP 管理接口，以及 Harness 原生右侧栏中的自动化页面。页面复用 Devflow UI 的页类型注册和 keyed slot 形式，不依赖当前会话，也不替换已有看板。

所有入口调用原有公开服务。计划、订阅、运行、取消记录、容量限制和消费确认位置仍由这些服务持有。工具调用者来自真实执行上下文；Web 接口执行现有本地宿主请求信任检查后记录人工入口。请求与响应经过协议校验，外部正文按文本呈现。

页面分开显示订阅、计划和运行记录，保留投递与下游状态的区别。可见页面刷新持久化状态，刷新失败时保留已有数据。GitHub 计划通过表单创建或修改；通用处理器参数编辑器及动态表单生成不在本轮范围。

## Alternatives considered

**包装斜杠命令。** 会重复解析逻辑，损失结构化参数、调用者归属和原生工具结果展示。

**嵌入 Devflow 看板。** 定时器是宿主级能力，也服务于与 Devflow 工作区无关的消费者。独立原生页面可保留现有看板体验。

**新建管理状态机。** 在 HTTP 或 React 中重复恢复、取消和接收规则，会使同一操作因入口不同而产生不同结果。

## Consequences

用户可直接操作面板，也可通过模型工具操作，并看到相同持久化结果。浏览器或工具不可用不影响后台提供者运行。浏览器产物必须使用已发布的 Harness 模块表，并共用 loader-factory 构建预设。真实 Loader、工具、HTTP 和组件检查之外，另行记录打包 profile 与浏览器验收。

## 验证

使用 Node 24.18.0 和 pnpm 11.24.0：132 个测试文件、1,653 项测试通过；包与工具 TypeScript 检查通过；lint 无错误（有三条既有的未使用 disable 警告）。全仓库逐文件的语句、分支、函数和行覆盖率均为 100%（6,418 条语句、4,253 个分支、1,549 个函数、5,552 行）。清理后构建及 29 个包的 tarball 预检通过。

真实 Loader 组合验证工具与 HTTP 共用订阅、计划和运行状态，包括从另一入口恢复失败同步。浏览器回归测试覆盖慢请求的单请求并发和错误独立保留；响应解码回归验证长名称及处理器身份保持原值。

隔离的打包 Web profile 在 756px 和 1440px 浏览器宽度下完成原生侧栏验收：创建订阅、立即同步、纯文本 Issue 内容、创建间隔计划、手动触发、暂停与恢复，以及完成后的运行历史。GitHub 使用本地回环 fixture；Harness 宿主、插件 Loader、SQLite 服务、HTTP 和浏览器客户端均为真实实现。真实工具运行时发现了 17 个工具并完成查询调用。未进行 LLM 请求或真实 GitHub 账号同步。

四个消费者 tarball 经 Harness CLI 安装到本地 Web profile，安装前已备份配置。原生“自动化”入口及空订阅面板正常加载，浏览器无警告或错误；实时 HTTP 概览报告两个服务均可用。未向该 profile 写入测试订阅或计划。宿主运行版本为 0.1.5-rc.2-fb2c4b9；包依赖和组合测试使用已发布的 0.1.5-rc.2 接口。
