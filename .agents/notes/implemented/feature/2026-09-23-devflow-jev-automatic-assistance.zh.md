# Agent Note: 有界的 Devflow JEV 自动研发辅助

Status: implemented

## Problem

提示词指引让 agent 知道 JEV 的存在，但每次调用仍依赖 agent 自行选择。研发过程中，本地工具结果和 checkout 变化可能已足以提出一个有界问题，重复失败或验证缺失却仍未被发现。单独记录判断，也无法让用户区分观察、投递和实际结果。

## Decision

实现涉及三个已有包。devflow-jev 持有自动辅助服务、配置、策略、工作区证据采集器和持久化记录存储。通用 jev 运行时新增可选 configurationIdentity() 元数据，供消费方使缓存失效。TypeSafe 提供方将其实现为提供方、模型、端点及凭据引用的不透明指纹，不包含凭据值。该身份描述配置，不证明提供方健康，也不识别同一引用背后的密钥轮换。通过已发布的 Harness 工具结果及 agent 生命周期钩子观察已识别的研发事件，在有预算限制的检查点调用既有领域无关 JEV seam，并可向当前 agent 提供建议。它不执行研发命令、不推进卡片，也不放宽验证要求。

默认 observe 模式采集符合条件的证据并记录判断，不投递建议。Assist 通过当前 agent 投递建议；off 关闭自动钩子，保留显式工具及已有指引。每轮调用和纠偏次数、判断截止时间、置信度门槛以及证据字节和文件数量限制均由已校验配置控制。识别特定工具结果，不代表支持任意工具协议。

策略版本 2 从已提供需求或实际失败的工具结果中选择具体调查目标，并明确标记建议尚未验证；无法确定归属时仍可选择 scope。调用预算至少为两次时，中间检查点为完成检查或重复失败保留最后一次调用。由 observe 切换为 assist，或恢复本地凭据配置后，去重允许在剩余预算内重新评估；相同证据、事件、策略版本及提供方配置身份下，已投递和投递结果不确定的记录仍不会重放。

证据标识真实 checkout 与被观察会话。卡片关联需要已支持的成功工具结果和所有权检查；存在歧义或派发 worktree 归属未经验证时，只保留会话范围。有界 git/源码证据和工具结果显式携带缺口。不可信证据不能提供可执行命令或授权操作。阶段评估消费相关的类型化答案，不把 intake 分数当作发布许可。

采集器保留会话的规范化目录，不自动扩展到 Git 仓库根目录。已提供文件使用内容哈希；被排除的隐藏或大文件只贡献不透明的本地元数据/index 摘要，不暴露其内容。稳定遗漏项仍保留为明确缺口。枚举截断、元数据不可读或采集时变化会让本次观察不可复用。这样可以提出有界建议，同时不把局部覆盖当成完整验证。

记录存储在 `.devflow/judgements/assistance/`，把触发、行动及原因与投递状态、观测结果分开保存，并分别保留行动选择集中度与干预支持概率。后续行动或检查的观测详情包含真实工具调用编号及可用的退出状态；这些引用证明发生过观察，不证明因果关系。先持久化再发布；重启后不会盲目重放投递结果不确定的记录。取消、证据过期、缺少凭据和预算用尽都保留为本次辅助尝试的可见状态。Devflow journal 继续作为卡片状态权威。

已有来源注册表通过 jev_list 提供只读 devflow-assistance 来源。可信 HTTP 查询从指定会话派生项目，不接受任意文件系统根目录。现有 JEV 面板增加“自动辅助”筛选与详情，可按关联卡片编号、标题、会话编号和原因搜索。界面显示证据引用及缺口，不展示完整采集源码。本版不在 Devflow 卡片详情内部嵌入时间线。

## Alternatives considered

**仅使用提示词指引。** 指引仍有价值且可独立启用，但不会根据已观察到的研发事件生成持久化记录。

**单独的执行器或强制语义门禁。** 前者重复 Harness 执行权，后者把概率性建议当成工作流状态迁移许可。自动辅助向当前 agent 提供有预算限制的建议，保留原门禁。

**新增一组模型工具与包。** 现有来源注册表、项目 HTTP 路由和审查面板已经负责查询与展示。扩展这些入口能保留统一的生命周期词汇，避免再引入一套编排入口。

## Consequences

Observe 模式允许在启用投递前观察干预质量，同时会为符合条件的事件增加判断延迟和提供方用量。Assist 仍是建议，需要 agent 选择适当行动。没有证据时结果保持未知；后续行动和检查不能仅因出现在建议之后，就被认定为采纳、因果或问题解决。

确定性的 UI、传输和组合测试验证记录可见性、项目隔离、可选服务生命周期，以及投递和结果的区分。它们不能证明 TypeSafe 当前可用、自然任务成功或普遍提效；这些需要单独的运行与对照证据，并保留失败或无益的干预样本。
